# How to manually run:
1. Install poetry
2. Install requirements using 'poetry install' command
3. Install FFmpeg and make sure it is available in PATH
4. Create config.json with structure like sampleconfig.json
5. Enter poetry venv with 'poetry shell' command and run 'python3 main.py'

Optional: add YouTube cookies to `yt_cookies.txt` if yt-dlp needs them for some videos.
